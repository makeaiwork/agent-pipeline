# Blockers

Open blockers of the pipeline. The runner writes here on `BLOCKED` (round 2 review did not give
`APPROVE`, both reviewers are unavailable, the task requires the owner's decision) — one section per
blocker:

```
## <ID> — <the gist in one line> (<date>)

- What it got stuck on: …
- What has already been done (worktree/branch, if code was left uncommitted): …
- What is needed from the owner: …
```

Closed blockers are moved to `blockers-archive.md`; here — open ones only.
